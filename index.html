v1.0

New rank system + Retakes mode

Sep 13

Two changes landed in the community mod today — both requested by pretty much everyone in the Discord since day one.

New rank system

Every player now gets tracked with a proper rank instead of a raw win count. It updates after every match and factors in round impact, not just the final score, so a close loss still counts for something.

Retakes mode

A full Retakes mode is now available for warmup and off-hours practice. Bomb is already planted, one side defends, one side retakes — quick rounds, no economy to manage.

Both are live right now on the servers. Bug reports and feedback go straight into Discord as always.
